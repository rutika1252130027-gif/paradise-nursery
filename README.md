# Paradise Nursery Shopping Application

Paradise Nursery is an interactive e-commerce web application built with React and Redux Toolkit. Users can browse categorized houseplants, add them to a dynamic shopping cart, manage quantities, and calculate total costs seamlessly.

## Features
- **Landing Page:** Welcome screen with background visuals and a "Get Started" button.
- **Product Catalog:** 18 unique houseplants divided into 3 categories (Air Purifying, Aromatic, and Medicinal) with pricing, descriptions, and dynamic "Add to Cart" states.
- **Redux State Management:** Global shopping cart management using Redux Toolkit (`CartSlice.jsx`).
- **Dynamic Shopping Cart:** Real-time calculation of item subtotals, grand total, item removal, and quantity adjustments.
- **Navigation:** Seamless navigation between landing page, plant listing, and cart view.

## Tech Stack
- React.js
- Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- CSS3
